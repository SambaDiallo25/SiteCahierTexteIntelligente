## 📋 Description du projet

**CahierSmart** est une application web permettant de :
- 📖 Gérer les cahiers de texte numériques
- 🤖 Automatiser le suivi des cours grâce à l'IA
- 👩‍🏫 Aider enseignants et étudiants à mieux s'organiser
- 🔔 Envoyer des notifications intelligentes

## 🚀 Lancer le projet en local

1. **Cloner le repository :**
```bash
git clone https://github.com/[votre-org]/cahiersmart.git
cd cahiersmart
```

2. **Ouvrir le site :**
   - Double-cliquer sur `index.html`
   - Ou utiliser l'extension **Live Server** sur VS Code

> ⚠️ Aucune installation requise. Le projet fonctionne avec HTML, CSS et JS purs.

## 🌿 Workflow Git — Comment contribuer

### Branches du projet

| Branche | Utilisation |
|---------|-------------|
| `main` | Version stable et validée |
| `dev` | Branche de développement principal |
| `feature/nom-tache` | Une branche par fonctionnalité |

### Étapes pour contribuer

```bash
# 1. Se placer sur dev et mettre à jour
git checkout dev
git pull origin dev

# 2. Créer sa branche de travail
git checkout -b feature/ma-fonctionnalite

# 3. Faire ses modifications, puis committer
git add .
git commit -m "feat: description claire de ce qui a été fait"

# 4. Pousser sa branche
git push origin feature/ma-fonctionnalite

# 5. Créer une Pull Request vers dev sur GitHub
```

### Convention de nommage des commits

| Préfixe | Utilisation |
|---------|-------------|
| `feat:` | Nouvelle fonctionnalité |
| `fix:` | Correction de bug |
| `style:` | Modification CSS/design |
| `content:` | Ajout ou modif de contenu |
| `docs:` | Modification du README |
| `refactor:` | Réorganisation du code |

**Exemples :**
```
feat: ajout de la section hero sur index.html
fix: correction du menu burger sur mobile
style: amélioration des couleurs des cartes
content: rédaction du texte de la page about
```
